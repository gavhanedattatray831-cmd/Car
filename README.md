# Car Sales and Price Analysis

A dashboard to analyze used car sales and prices.

## Features
- 300 car records (brand, model, year, KM driven, fuel type, transmission, owner, city, price in INR)
- Charts for price trends, brand-wise sales, fuel type and city comparison
- Built with HTML, CSS and JavaScript

## Live Demo
https://gavhanedattatray831-cmd.github.io/Car/

## Files
- index.html - dashboard page
- script.js - data and charts
- style.css - styling
